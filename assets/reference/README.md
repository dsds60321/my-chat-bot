# 디자인 참고 자료

사용자가 프로젝트 루트 `../../pet.png`를 챗봇 이미지로 지정했다. 1536×1024, 알파 채널이 있는 PNG 원본이며 실제 이미지를 열어 크림색/골드와 네이비의 고양이 귀 로봇을 확인했다. 원본은 이 폴더로 이동하거나 덮어쓰지 않고 그대로 보존한다. 공식 회사 로고로 간주하지 않는다.

데스크톱 펫은 이 PNG를 사용한다. 이전 임시 SVG는 현재 채택 이미지가 아니며 총괄이 참조 제거를 확인한 뒤 삭제할 수 있다. 이미지 편집이나 외부 이미지 생성 도구 사용은 없었다. 정적 Phase 1에는 3D 리소스가 필요하지 않다.

96px 표시에는 전체가 보이는 CSS `object-fit:contain`을 기본으로 하고, 더 큰 표시를 위한 `cover`의 좌우 크롭 한계는 `../../docs/design-system.md`에 기록했다. 발광 배경은 완전한 누끼로 가정하지 않으며 실제 투명창에서 확인해야 한다. 화면 상태와 접근성 기준도 같은 문서를 따른다.
